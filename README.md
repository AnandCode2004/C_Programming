# C Programming

## About

This repository contains C programs, programming exercises, and assignment solutions.

## Repository Structure

- **Assignments/** – Solutions organized by assignment.
- **Problem-Solving/** – Programs organized by day.

## Purpose

To practice C programming, strengthen logical thinking, and improve coding skills.

## Topics

- Programs based on basic algorithmic strategy
- Programs based on Selection technique
- Programs based on Iteration technique
- Programs based on Functional approach
- Programs based on Numbers

## Language

- C


  ## How to Use

1. Browse the `Assignments/` or `Problem-Solving/` folder.
2. Open the required assignment or day folder.
3. Open a `.c` file to view the source code.
4. Compile and run the program using a C compiler, such as GCC.
5. Test the program with different inputs to understand its output.

## Example

&#x20;open command prompt using ( Win + R) go to the path where your where your program is save then write this command
